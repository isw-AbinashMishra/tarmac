README & help — setup, backup, applets, adding groups & quotas

Set as your Chrome homepage / startup page

  1. Chrome → ⋮ → Settings → On startup → “Open a specific page or set of pages”.
  2. Click Add a new page and paste this file’s address (e.g. file:///D:/source/tarmac/index.html).
  3. For the home button: Settings → Appearance → enable Show home button → enter the same address.
  4. Tip: pin the tab (right-click tab → Pin) so it survives restarts.

Backup: how Export / Import works

All data lives in your browser’s localStorage (key tarmac:state), which is per-browser and per-profile. Export downloads a tarmac-backup-*.json snapshot; Import validates and loads one back (replacing current state). A bad file shows an error and leaves your data untouched. Export before switching machines or clearing browser data.

Enable / disable / reorder applets

Reorder in-app: click Arrange in the toolbar, then drag cards into the order you want (or focus a card and use the arrow keys). Click Done when finished — the order is saved automatically.

Applets are also config-driven. Edit state.applets.order (the list of applet ids, top-to-bottom) and state.applets.disabled (ids to hide). Do it by editing CONFIG.applets in the source for a fresh install, or Export → edit the JSON → Import. Applet ids: clock, quota, deepwork, tally, water, walks, capacity, todo, standup, blockers, snippets, decisions, bookmarks, quotes.

Add a bookmark group

  • In-app: click + Group, then + Link inside a group. Hover a tile → the pencil edits it.
  • In code: edit CONFIG.bookmarkGroups near the top of the JS. Each group is { label, links: [{ label, url, icon }] }. (CONFIG only seeds a fresh install.)

Add a quota widget

  • In-app: click + Add on the Quota card.
  • In code: add an object to CONFIG.quotas: { label:"OpenAI", unit:"$", monthlyLimit:120, used:0, resetDay:1, source:"manual" }. The pace badge compares usage against a straight-line expectation for how far you are into the reset cycle.

Where day-scoped data lives

Standup notes, deep-work counts, the meeting/focus tally, and the water/walk-break counts are stored per day under state.daily["YYYY-MM-DD"]. Today’s key is computed on load and on tick, so buffers roll over automatically at local midnight. Past days are kept for history and pruned after 30 days.

Add a new applet

See the big comment block at the top of the <script> (“HOW TO ADD A NEW APPLET”): add its state slice, call registerApplet({...}), and add its id to CONFIG.applets.order.
